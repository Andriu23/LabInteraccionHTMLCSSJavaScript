# 🌐 Actividad: HTML, CSS y JavaScript

## 📚 Descripción

En esta actividad se trabajará con **HTML, CSS y JavaScript**, aplicando conceptos básicos de estructura, estilos y manipulación del **DOM (Document Object Model)**.

El objetivo es enlazar correctamente los archivos `style.css` y `script.js` con el documento HTML y agregar diferentes elementos y funcionalidades al sitio web.

---

## 🎯 Objetivos

* Crear y modificar elementos HTML.
* Utilizar atributos `id` y `class`.
* Aplicar estilos mediante CSS.
* Enlazar JavaScript con HTML.
* Manipular elementos del DOM mediante JavaScript.
* Responder a eventos como el clic.
* Modificar contenido y estilos dinámicamente.

## 📝 Actividad

### 🔹 Sección HTML

Realizar las siguientes modificaciones en el archivo `index.html`:

* Añadir un encabezado que diga **"¡Hola mundo!"**.
* Insertar una imagen desde el directorio `images`.
* Añadir un atributo `id` con el valor **"rojo"**.
* Añadir cuatro encabezados más que digan **"Hola mundo"**.
* Añadir dos atributos `class` con el valor **"azul"**.

### 🔹 Sección CSS

En el archivo `style.css`:

* Enlazar el archivo CSS con el documento HTML.
* Hacer que todos los elementos `h1` tengan el color **verde**.
* Crear la clase `.azul` y aplicar el color **azul** al texto.
* Crear el selector `#rojo` y aplicar el color **rojo** al texto.

### 🔹 Sección JavaScript

* Enlazar JavaScript con HTML.
* Modificar el primer **"¡Hola Mundo!"** para que diga **"Adiós"** mediante JavaScript.
* Cambiar mediante JavaScript el color de fuente de un encabezado a **naranja**.
